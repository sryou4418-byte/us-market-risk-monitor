> 다음 핵심 작업: **시장 상태 v0.4 전체 데이터 확보와 발표시점 정합성 검증 → 1년 전체 검증 및 5~10년 임계값 보정 → Breadth·실물 수급 연결**

## 0. 가장 먼저 읽을 요약

이 프로젝트는 단순히 현재 미국 증시 숫자를 나열하는 대시보드가 아니다.
**시장·밸류에이션, 변동성, 금리, 신용, 경기, 물가를 0\~100 위험점수로
정규화하고, 구조적 위험·시장 급변·진행 중 시장 스트레스를 별도로 감지해
최종 종합위험지수를 만드는 개인용 미국 증시 모니터링 프로그램**이다.

제품 철학은 iOS 계열의 단순하고 직관적인 UI다. 첫 화면에서는 사용자가 약
3초 안에 현재 시장 위험도를 이해할 수 있어야 한다. 반면 사이드바의 상세
페이지들은 대시보드보다 더 깊은 정보를 제공한다.

현재까지 역할을 다음처럼 구분했다.

-   **대시보드**: 3초 안에 현재 시장이 안정/주의/위험 중 어디에 가까운지
    파악.
-   **위험지수 페이지**: 종합위험지수가 왜 그 점수가 되었는지 자세히
    설명.
-   **시장 상태(시장현황) 페이지**: 대시보드보다 훨씬 많은 데이터를
    이용해 "시장 내부에서 실제로 무엇이 움직이고 있는가"를 진단하는
    페이지. 앞으로의 주 연구 대상.
-   **S&P500 시장맵**: 자체 경량 히트맵. 외부 iframe 의존을 줄임.
-   **뉴스**: 사이드바의 기존 알림 기능을 뉴스로 변경하는 방향.
-   **데이터/리포트/설정/도움말**: 후속 개발.

중요한 설계 원칙은 **AI가 시장을 자유 생성식으로 해석하지 않는다**는
것이다. 숫자를 먼저 규칙으로 상태화하고, 여러 지표의 교차 확인과
신뢰도를 계산한 뒤, 준비된 자연어 문구를 조합하는 **결정론적 규칙형 문장
엔진(작은 전문가 시스템)**을 사용한다. 장점은 빠르고, 비용이 없고, 같은
데이터에 항상 일관된 설명을 만들 수 있다는 것이다.

# 1. 프로젝트 개발 철학과 확정된 UX 원칙

## 1.1 전체 UI

-   iOS식 디자인 철학.
-   처음 실행한 사용자가 약 3초 안에 현재 시장 상황을 이해할 수 있어야
    한다.
-   종합위험도를 가장 크게 표시.
-   금리·경기·변동성·신용·시장·물가 등 카테고리는 카드형.
-   세부지표는 **현재값**과 **위험도(0\~100)**를 혼동하지 않도록 명확히
    분리.
-   색은 최소화하고 위험 상태 표현에 집중.
-   색만으로 의미를 전달하지 않고 텍스트 상태도 병기.
-   필요한 지표에는 설명 `ⓘ`.
-   메인 화면 → 카테고리 → 세부지표 순으로 깊어지는 구조.
-   모바일에서도 카드가 무너지지 않아야 함.
-   증감값이 음수이면 하락 색은 **파란색**, 양수/위험 상승은 붉은 계열.
-   카드 제목의 아이콘은 의미와 일치해야 함. 예: 시장 급변은 작은 그래프
    계열, 물가는 화폐/가격을 연상시키는 아이콘.
-   사이드바는 긴 항목(`S&P500 시장맵`)이 줄바꿈되지 않도록 충분한 폭을
    확보.
-   사이드바에서 클릭 가능한 글씨가 파란 링크처럼 보이는 것은 가독성이
    떨어져 흰색 계열로 맞추는 방향.
-   상단 `데이터 업데이트` 버튼은 실제로 작동해야 함.
-   다크모드도 실제로 동작하는 방향.
-   페이지 전환은 새 탭을 열지 않고 **현재 앱 내부에서 전환**되어야 함.
-   무거운 기능은 초기 로딩 때 전부 계산하지 않고 **사용자가 해당
    페이지/기능을 눌렀을 때 지연 로딩(lazy loading)**.

## 1.2 성능 원칙

개발 중 히트맵, 다크모드, 페이지 이동 등을 누를 때 Streamlit 전체
rerun으로 체감 지연이 발생하는 문제가 있었다. 이후 방향은 다음과 같다.

-   초기 대시보드에서 불필요한 무거운 계산 금지.
-   최근 1년 위험지수 추이 등은 버튼을 눌렀을 때 계산.
-   데이터는 캐시 활용.
-   데이터 업데이트는 가능한 한 백그라운드/부분 갱신.
-   페이지 전환도 가능한 한 세션 상태를 이용해 필요한 부분만 표시.
-   히트맵 역시 별도 페이지에서 불러오기.
-   자체 경량 S&P500 히트맵은 200종목 수준까지 테스트했을 때 체감 성능이
    양호했음.

# 2. 현재 최신 버전과 최근 변경 이력

## 2.1 최신 버전

**v3.43.1**

v3.43.0에서 위험지수 상세 페이지용 자연어 문장 엔진을 적용했고,
v3.43.1에서 위험지수 페이지 전체 폰트를 확대했다.

### v3.43.0

-   위험상황 요약 및 `오늘 점수가 나온 이유`를 단순 고정문장 방식에서
    **규칙형 자연어 문장 엔진**으로 변경.
-   가장 큰 위험요인, 두 번째 위험요인, 가장 안정적인 요인, 구조적 신호,
    급변 신호를 조합.
-   전문 보고서식 표현을 줄이고 즉시 이해 가능한 한국어로 변경.
-   예: `즉각적인 시장 스트레스는 제한적입니다.` 같은 문장은 폐기.
-   대체 예: `지금 당장 시장이 크게 흔들릴 조짐은 많지 않습니다.`
-   AI/API 호출 없음.
-   위험 산식은 변경하지 않음.

### v3.43.1

-   위험지수 상세 페이지 폰트 전체 확대.
-   종합 점수, 섹션 제목, 이유 문장, 구성요소 점수/설명, 구조·급변 신호,
    위험구간 라벨 등을 확대.
-   모바일 폰트도 함께 확대.
-   위험 산식 변경 없음.

## 2.2 바로 이전 중요 수정

### v3.42.2

-   위험지수 상세 페이지의 구조적 위험신호 개수와 시장 급변신호 개수가
    실제 엔진의 `count`와 다르게 표시되는 문제 수정.
-   구조적 위험신호 → `structure["count"]`
-   시장 급변신호 → `rapid["count"]`
-   `오늘 점수가 나온 이유`도 실제 감지 개수와 신호명을 사용하도록 수정.

### 위험지수 상세 페이지 설계 과정

사용자는 사이드바의 `위험지수`를 눌렀을 때 대시보드보다 더 자세한 이유를
볼 수 있기를 원했다. 확정된 핵심은: - 위험지수 자체 - 구조적 위험 - 시장
급변 - 점수가 만들어진 과정 - 6대 구성요소 - 오늘 점수가 나온 이유 여러
개 - 최근 1년 추이 - 계산 기준 을 상세 페이지에서 보여주는 것.

# 4. 6대 카테고리 산식 상세

## 4.1 시장·밸류에이션

세 요소: 1. S&P500의 200일 이동평균선 대비 이격도(과열) 2. CAPE 3. 최근
20거래일 모멘텀

가중치:

``` text
시장·밸류에이션 =
  200DMA 과열 45%
+ CAPE        35%
+ 20일 모멘텀 20%
```

### 200DMA 이격도 → 과열점수

``` text
이격도(%): -15, -5, 0, 5, 10, 15, 20
점수:       0,  5,15,40, 70, 90,100
```

중요: 이 항목은 **폭락 후의 스트레스가 아니라 폭락 전 가격 과열
취약성**을 보려는 목적이다.

### CAPE → 점수

``` text
CAPE:  10,15,20,25,30,35,40,45
점수:   5,10,25,45,65,80,92,100
```

### 20일 모멘텀

20거래일 수익률:

``` text
수익률(%): -12,-6,0,3,6,10,15
원점수:      0, 5,10,30,55,80,100
```

단, 폭락 후 기술적 반등을 과열로 잘못 해석하지 않도록 200DMA 이격도에
따라 모멘텀 점수를 gate한다.

-   이격도 ≤ 0: 영향 25%
-   0\~5%: 25%에서 60%로 점진 증가
-   5\~10%: 60%에서 90%로 증가
-   ≥10%: 100% 반영

## 4.5 경기

구성:

``` text
경기 위험 =
  실업률 절대수준 30%
+ Sahm Rule       35%
+ 신규실업수당    35%
```

### 실업률

``` text
실업률(%): 3,3.5,4,4.5,5,6,8,10
점수:      10,15,25,40,55,70,90,100
```

### Sahm Rule

``` text
Sahm: 0,.1,.2,.35,.5,.75,1.5
점수:  5,15,30, 50,70, 90,100
```

중요한 확정 원칙: - Sahm Rule 단독 신호로 강한 경기침체 판정을 내리지
않는다. - 신규실업수당 최근 추세가 함께 악화될 때 강한 신호로 인정. -
Sahm ≥ 0.5라도 신규실업수당 확인이 없으면 Sahm 점수를 최대 55로 제한.

### 신규실업수당

-   4주 이동평균 사용.
-   노동시장 규모 변화 때문에 절대 건수만 사용하지 않고 **과거 10년 상대
    백분위** 사용.
-   최근 약 8주 추세도 반영.
-   8주 변화율 매핑:

``` text
변화율(%): -20,-5,0,+5,+10,+20,+40
점수:        0, 5,15,30, 50, 75,100
```

## 4.6 물가

CPI, Core CPI, Core PCE를 사용.

각 지표는: - YoY 수준 - 최근 3개월 연율화 를 결합한다.

Headline CPI:

``` text
YoY 55% + 3개월 연율 45%
```

Core CPI / Core PCE:

``` text
YoY 45% + 3개월 연율 55%
```

최종 물가 카테고리:

``` text
Headline CPI 25%
Core CPI     35%
Core PCE     40%
```

### YoY 점수

``` text
물가(%): 0,1,2,2.5,3,4,6,8,10
점수:    5,10,20,35,50,70,90,98,100
```

### 3개월 연율화 점수

``` text
3m ann(%): -2,0,1,2,2.5,3,4,6,8,10
점수:        0,5,10,20,35,50,70,90,98,100
```

# 5. 구조적 위험 신호

구조적 위험은 **수개월\~1년 지속될 수 있는 취약성**을 따로 감지한다.
기본 종합점수와 별개로 "시장 바닥 위험도를 일정 수준 아래로 떨어뜨리지
않는 하한(floor)" 역할을 한다.

현재 감지 항목:

1.  **장단기 금리 역전 이력**
2.  **시장 고평가**
3.  **물가 재가속**
4.  **고용 악화 확인**

## 5.1 장단기 금리 역전 기억

10Y-2Y가 음수였던 마지막 시점을 기억한다.

-   역전 종료 후 6개월까지 위험 기억 100%
-   6\~18개월 사이 선형 감소
-   18개월 이후 0
-   기억 점수 ≥25면 구조적 신호로 카운트

즉 역전이 끝났다고 다음날 바로 위험신호를 삭제하지 않는다.

## 5.2 시장 고평가

시장·밸류에이션 내부의 valuation(CAPE) 점수 ≥85.

## 5.3 물가 재가속

-   최근 3개월 물가 모멘텀 합성점수 ≥70
-   그리고 최근 모멘텀이 YoY 위험도보다 같거나 높음

## 5.4 고용 악화 확인

-   Sahm Rule 실제값 ≥0.5
-   신규실업수당 추세 확인(`claims_confirm=True`)
-   둘이 동시에 충족되어야 구조적 고용 악화로 인정.

## 5.5 구조 신호 단계

``` text
0개 = 정상
1개 = 관찰
2개 = 주의
3개 이상 = 경계
```

# 6. 시장 급변 신호

구조적 위험과 달리 **수일\~수주 단위의 빠른 시장 스트레스**를 감지한다.

현재 빠른 축:

-   VIX
-   신용
-   10년물 금리 상승속도
-   고용(신규실업수당 추세)

각 축의 fast score가 **70 이상**이면 활성 신호로 카운트.

### 급변 판정

-   1개 이상 → `관찰`
-   2개 이상이면서 이전에도 2개 이상이거나, VIX/신용이 동시에 극단 →
    `급변 경보`
-   3개 이상이며 이전에도 복수 신호 또는 85점 이상 극단축 2개 이상 →
    `강한 스트레스`

극단 기준: - VIX fast score ≥85 - 신용 fast score ≥80

핵심 철학: \> 급변축 1개만으로 시장 위기를 선언하지 않는다. 2개 이상
동시 확인을 중요하게 본다.

# 7. 신호 하한(floor)과 진행 중 시장 스트레스

최종 위험지수는 단순 가중평균만 사용하지 않는다.

``` text
Final Risk = max(
    Base Risk,
    Structural/Rapid Signal Floor,
    Active Market Stress Floor
)
```

## 7.1 구조/급변 하한

``` text
구조 1개               → 최소 40
구조 2개 이상          → 최소 50
급변 2개               → 최소 55
급변 3개 이상          → 최소 65
구조≥2 + 급변≥2        → 최소 65
구조≥2 + 급변≥3        → 최소 70
```

## 7.2 진행 중 시장 스트레스

S&P500의 최근 1년 고점 대비 낙폭, 5일/20일 하락 속도, VIX 또는 신용
확인을 함께 사용.

### 조정 스트레스

-   drawdown ≤ -10%
-   5일 ≤ -5% 또는 20일 ≤ -8%
-   VIX ≥25 또는 신용 fast ≥60 → floor 55

### 강한 스트레스

-   drawdown ≤ -15%
-   5일 ≤ -7% 또는 20일 ≤ -12%
-   VIX ≥30 또는 신용 fast ≥70 → floor 65

### 위기 수준

-   drawdown ≤ -20%
-   5일 ≤ -10% 또는 20일 ≤ -15%
-   VIX ≥40 또는 신용 fast ≥85 → floor 75

이 구조는 "폭락이 이미 진행 중인데 밸류에이션 과열점수는 오히려 내려가서
종합위험이 낮아지는" 문제를 막기 위한 장치다.

# 8. 위험지수 상세 페이지 문장 엔진

## 8.1 왜 만들었는가

초기에는 다음처럼 보고서식/고정식 문구가 많았다.

> 즉각적인 시장 스트레스는 제한적입니다.

사용자는 이런 문장이 한 번에 이해되지 않는다고 지적했다. 따라서 목표를
다음으로 바꿈.

> **전문용어를 줄이고, 사용자가 읽자마자 시장 상황을 이해할 수 있는
> 자연스러운 한국어.**

예:

> 지금 당장 시장이 크게 흔들릴 조짐은 많지 않습니다.

## 8.2 현재 v3.43.0+ 구조

완전한 생성형 AI가 아니다.

``` text
숫자
 ↓
위험 구간 판정
 ↓
가장 큰 위험요인 / 두 번째 위험요인 / 안정요인 선정
 ↓
구조적·급변 신호 확인
 ↓
상황별 문구 조각 선택
 ↓
요약문 + 오늘 점수가 나온 이유
```

위험 구간은 대략: - very_high - high - elevated - normal - low

카테고리별 문구 은행: - 시장·밸류에이션 - 변동성 - 금리 - 신용 - 경기 -
물가

### 문장 구성 원칙

1.  가장 큰 위험요인은 반드시 설명.
2.  두 번째 위험요인은 의미 있게 높을 때만 추가.
3.  실제로 안정에 기여하는 항목이 있으면 안정요인 하나 추가.
4.  구조적 신호가 있으면 신호명을 가능하면 직접 언급.
5.  급변 신호가 있으면 단기 경고.
6.  급변 신호가 없으면 어려운 금융용어 대신 평이한 결론.
7.  중복 문장은 제거.
8.  너무 많은 이유를 늘어놓지 않고 최대 약 5개.

### 예시

금리 높음 + 변동성 안정 + 급변 없음:

> 현재는 금리 부담이 가장 큽니다. 반면 변동성은 비교적 안정적입니다.
> 지금 당장 시장이 크게 흔들릴 조짐은 많지 않습니다.

시장 고평가 구조신호:

> 중기적으로는 시장 고평가 신호가 잡혀 있어 조정 위험을 계속 지켜볼
> 필요가 있습니다.

## 8.3 이 엔진의 한계

현재 문장 엔진은 **위험지수 상세 설명용**이다. 앞으로 만들 `시장 상태`
페이지는 더 많은 지표와 교차관계를 해석해야 하므로, 기존 엔진을 그대로
쓰는 것이 아니라 **공통 자연어 레이어 + 시장상태 전용 규칙 세트**로
확장해야 한다.

# 9. 사이드바 `시장 상태`(시장현황) 페이지 --- 현재 논의의 핵심

## 9.1 페이지의 역할

확정된 역할 구분:

``` text
대시보드
= 3초 안에 “지금 시장이 괜찮은가/위험한가”

시장 상태
= 30초~2분 동안 “왜 그런가, 시장 내부에서 무엇이 먼저 움직이는가”
```

따라서 시장 상태는 단순한 `대시보드 지표 더보기`가 아니다.

**시장 진단실**처럼 설계한다.

## 9.2 시안 비교에서 확정된 방향

두 개 시안을 비교한 결과:

-   **구조는 2번 시안**
-   **시각적 여유는 1번 시안**

즉 정보량은 2번처럼 많게 가져가되, 1번처럼 여백이 있고 카드가 숨 쉬는
디자인.

2번 시안에서 특히 좋은 것으로 평가한 요소: -
`오늘 변화가 큰 지표 TOP 5` - `시장 내부 건강도` - 현재값뿐 아니라 최근
변화와 상대적 위치 - 각 섹션의 간단 해석 - 맨 아래 `시장 종합 해석`

# 10. 시장 상태 페이지에 넣기로 한 정보

## 10.1 최상단 --- 시장 한눈에 보기

6개 정도의 상태 카드:

-   주식
-   금리
-   신용
-   변동성
-   경기
-   물가

예: - 주식: 과열 - 금리: 부담 - 신용: 안정 - 변동성: 보통 - 경기: 보통 -
물가: 주의

각 카드에 한 줄 보조 설명.

## 10.2 오늘 변화가 큰 지표 TOP 5

사용자가 숫자 수십 개를 다 읽지 않아도 "오늘 어디가 움직였는지" 바로 알
수 있게 한다.

예: - 미국 10년물 +12bp - VIX +8.4% - HY OAS +7bp - S&P500 -0.7% -
원/달러 +0.4%

실제 구현 시 단순 변화율 크기만 정렬하지 말고 **각 지표의 정상 변동폭을
고려한 표준화/위험 변화 점수**를 연구할 가치가 있다.

## 10.3 주식시장 내부 건강도(Breadth)

대시보드와 시장 상태를 차별화하는 핵심.

후보: - S&P500 - Nasdaq - Russell 2000 - 20일 수익률 - 60일 수익률 -
200DMA 대비 위치 - 최근 고점 대비 낙폭 - 상승 종목 비율 - 200DMA 위 종목
비율 - 52주 신고가/신저가 - S&P500 Equal Weight vs Cap Weight - 대형주
집중도/시장 확산 여부

핵심 질문:

> 지수는 오르는데 실제로 많은 종목이 같이 오르고 있는가?

예: - S&P500 강세 + Breadth 약화 + Equal-weight 부진 → 대형주 집중 상승
가능성.

## 10.4 금리시장

-   10Y-2Y
-   10Y-EFFR
-   5일 변화

# 11. 시장 상태 전용 해석 엔진 --- 설계 초안

## 11.1 가장 중요한 원칙

**지표 하나만으로 강한 결론을 내리지 않는다.**

예: - 구리 하루 -3% → 경기침체라고 말하지 않음. - 금 하루 급등 →
공포라고 단정하지 않음. - VIX만 상승 → 금융위기라고 하지 않음.

해석 순서:

``` text
현재 수준
→ 변화 속도
→ 추세 지속성
→ 관련 지표 교차 확인
→ 반대 증거 확인
→ 신뢰도 결정
→ 문장 강도 결정
```

## 11.2 공통 상태 표현

모든 서로 다른 숫자를 내부 상태로 바꾼다.

예:

``` text
10Y = 상승 / 강함 / 5일·20일 지속 / 신뢰도 높음
구리 = 하락 / 보통 / 20일 지속 / 신뢰도 보통
VIX = 상승 / 약함 / 단기 / 신뢰도 낮음
```

UI용 최종 상태는 필요하면: - 안정 - 보통 - 주의 - 위험

등으로 정규화.

## 11.3 시간축 원칙

현재 합의한 초기 철학:

-   **1일 변화**: "신호"가 아니라 "움직임"
-   **5일 확인**: 단기 신호
-   **20일 같은 방향**: 추세
-   **관련 지표 동시 확인**: 신뢰도 상승

예:

``` text
구리 하루 -3%
→ 오늘 구리 가격이 크게 하락했습니다.

구리 5일 -5%, 20일 -8%
→ 구리 가격의 약세 흐름이 이어지고 있습니다.

+ Russell 약세
→ 경기 민감 자산이 함께 약해지고 있습니다.

+ 실업수당 악화
→ 경기 둔화 신호가 여러 지표에서 동시에 나타나고 있습니다.
```

## 11.4 신뢰도 규칙 초안

``` text
관련 지표 1개 = 참고 신호
관련 지표 2개 = 의미 있는 신호
관련 지표 3개 이상 같은 방향 = 강한 신호
명확한 반대 지표 존재 = 한 단계 낮춤
```

이 규칙은 아직 **백테스트 전의 초안**이며 확정 임계값이 아니다.

# 12. 시장 상태 규칙 --- 1차 가설

**중요: 아래 숫자는 시장 상태 엔진을 위한 연구용 v0.1 임계값이다. 기존
종합위험지수의 확정 산식과 혼동하지 말 것. 백테스트 후 변경 가능.**

## 12.1 주식 Breadth

목표: 지수 상승의 질을 판단.

초기 조합 예:

### 좁은 상승

-   S&P500 강세/고점권
-   상승 종목 비율 약화
-   Equal-weight가 cap-weight보다 부진
-   Russell 2000 부진

→ \> 지수는 강하지만 상승세가 일부 대형주에 집중되고 있습니다.

### 건강한 확산

-   S&P500 상승
-   Breadth 약 65% 이상
-   Russell/Equal-weight 동반 상승

→ \> 상승세가 시장 전반으로 넓게 퍼지고 있어 내부 흐름도 양호합니다.

`65%`, `45%` 등 Breadth 임계값은 아직 연구값. 1년 백테스트 후 조정.

## 12.2 금리 --- 연구용 초기값

10Y 기준 초안:

``` text
5일 +15bp 이상 → 상승 주의
5일 +25bp 이상 → 빠른 상승
20일 +40bp 이상 → 지속적 금리 압력
```

하지만 금리 상승만으로 위험을 선언하지 않는다.

예:

10Y↑ + VIX 안정 + HY 안정 → \> 장기금리가 오르고 있지만 금융시장
불안으로 번지지는 않고 있습니다.

10Y↑ + VIX↑ + HY↑ → \> 금리 상승이 주식과 신용시장 불안으로 확산되는
모습입니다.

## 12.3 신용

절대 수준과 변화속도를 반드시 분리.

예:

HY 낮은 수준 + 5일 소폭 확대 → \> 신용시장은 아직 안정적이지만 최근
스프레드가 조금 넓어지고 있습니다.

HY 높은 수준 + 빠른 확대 + BBB 동반 확대 → \> 기업 신용시장의 불안이
전반적으로 커지고 있습니다.

## 12.4 변동성

예:

VIX 14 → 16 → \> 변동성이 조금 높아졌지만 시장 불안이 큰 수준은
아닙니다.

VIX 18 → 27 + 주가 하락 → \> 시장 변동성이 빠르게 커지고 있습니다.

VIX 상승 + HY 확대 → 더 강한 경고.

## 12.5 구리

구리는 **단독 경기예측 지표가 아니라 확인 지표**로 사용.

구리만 약세: \> 구리 가격이 약세를 보이고 있습니다.

구리↓ + Russell↓: \> 경기 민감 자산이 함께 약해지고 있습니다.

구리↓ + Russell↓ + 고용 악화: \> 실물경기 둔화 가능성을 보여주는 신호가
늘어나고 있습니다.

## 12.6 금

금 상승 자체를 위험으로 보지 않는다.

금↑ + 주식↑ + VIX↓: \> 금 가격은 오르고 있지만 금융시장의 위험 회피
신호는 강하지 않습니다.

금↑ + VIX↑ + HY↑: \> 안전자산 선호와 금융시장 불안이 동시에 강해지고
있습니다.

## 12.7 은

은은 금과 산업금속의 중간 성격으로 교차 해석.

-   금↑ / 은↑ / 구리↑ → 상품/산업 수요 또는 인플레 성격 가능
-   금↑ / 은↓ / 구리↓ → 안전자산 선호 성격이 상대적으로 강할 가능성
-   금↓ / 은↑ / 구리↑ → 경기·산업 수요 개선 가능성

이 역시 단독 결론 금지.

## 12.8 WTI

WTI 상승만으로 물가 위험이라고 하지 않는다.

WTI 20일 급등: \> 유가가 빠르게 오르고 있습니다.

WTI↑ + CPI 3개월 연율↑: \> 에너지 가격과 최근 물가 흐름이 함께 올라
인플레이션 부담이 커질 수 있습니다.

WTI↑ + CPI↑ + 10Y↑: \> 물가 재상승 우려가 금리시장까지 영향을 주는
모습입니다.

# 13. 상황 대입 훈련 --- 이미 합의한 예시

## 상황 A --- 지수는 강하지만 내부는 약함

``` text
S&P500 20일 +5%
200DMA 대비 +11%
상승 종목 비율 43%
Equal-weight 20일 -1%
```

판정: - 지수 강세 - 내부 확산 약화 - 신뢰도 중간 이상

문장:

> S&P500은 강세를 이어가고 있지만 상승세가 시장 전체로 퍼지지는 않고
> 있습니다. 일부 대형주에 상승이 집중되고 있는지 주의해서 볼 필요가
> 있습니다.

## 상황 B --- 금리 충격이 금융시장으로 확산

``` text
10Y 5일 +28bp
VIX 17 → 26
HY OAS 5일 +24bp
S&P500 5일 -6%
```

판정: - 강한 단기 시장 스트레스 - 신뢰도 매우 높음

문장:

> 장기금리가 빠르게 오르는 가운데 주가 변동성과 신용시장 불안도 함께
> 커지고 있습니다. 단순한 주가 조정보다 넓은 시장에서 위험 신호가
> 나타나는 상황입니다.

## 상황 C --- 안전자산/경기우려 가능성, 아직 확인 부족

``` text
금 20일 +8%
구리 -7%
VIX +20%
실업수당 안정
HY OAS 안정
```

판정: - 경기 우려 가능성 - 금융/고용 확인 부족 - 신뢰도 보통

문장:

> 금은 강한 반면 구리는 약해 안전자산 선호와 경기 우려가 일부 나타나고
> 있습니다. 다만 고용과 신용시장은 아직 안정적이어서 경기 악화를 강하게
> 판단하기는 이릅니다.

## 상황 D --- 물가 재가속

``` text
WTI 20일 +14%
Core CPI 3개월 연율 상승
Core PCE 3개월 연율 상승
10Y 20일 +35bp
```

판정: - 인플레이션 재가속 위험 - 신뢰도 높음

문장:

> 에너지 가격 상승과 최근 물가 지표의 재가속이 함께 나타나고 있습니다.
> 장기금리도 오르고 있어 물가 부담이 다시 금융시장에 영향을 주는
> 모습입니다.

## 상황 E --- 경기 둔화 + 금융시장 확인

``` text
구리 -9%
Russell 2000 -8%
신규실업수당 4주 평균 상승
HY OAS 확대
VIX 23
```

판정: - 경기 둔화 - 금융시장 확인 - 강한 신호

문장:

> 경기 민감 자산이 약해지는 가운데 고용과 신용시장에서도 둔화 신호가
> 나타나고 있습니다. 경기 우려가 단순한 자산가격 움직임을 넘어 여러
> 시장으로 확산되는지 주의가 필요한 상황입니다.

# 14. 시장 상태 문장엔진이 지켜야 할 금지 규칙

향후 구현자가 반드시 지킬 것.

1.  하루 변화 하나로 `경기침체`, `위기`, `공포` 같은 강한 표현을 쓰지
    않는다.
2.  금 상승 = 공포로 단정하지 않는다.
3.  구리 하락 = 경기침체로 단정하지 않는다.
4.  VIX 상승 하나만으로 금융위기를 선언하지 않는다.
5.  WTI 상승 하나만으로 인플레이션 재가속을 선언하지 않는다.
6.  시장상태 문장과 기존 종합위험지수 카테고리 판정이 서로 정면 충돌하지
    않도록 한다.
7.  반대 증거가 있으면 반드시 문장 강도를 낮춘다.
8.  데이터 부족은 억지로 추론하지 않고 `확인 부족`으로 표현.
9.  예측처럼 말하기보다 **현재 관찰되는 상태와 확인 조건**을 설명.
10. 사용자에게 바로 의미가 전달되는 쉬운 한국어 사용.

## 17.2 자체 경량 히트맵

결국 **자체 경량 treemap/heatmap**을 만들었다.

확정된 방향: - S&P500 구성 종목을 타일로 표시. - 시가총액/구성비율에
가까운 값으로 타일 크기 조정. - 상승/하락을 색으로 표현. - 작은 타일은
억지로 글자를 표시하지 않음. - 클릭/탭하면 티커와 기업명 등 정보 표시. -
정보 팝업은 타일 내부에 갇히지 않고 밖으로 나와야 함. - 팝업은 선택한
티커 상자의 **왼쪽 위 근처**에 보이게 하는 방향. - 모바일에서는 확대/탭
탐색을 고려. - 섹터/카테고리 폰트를 크게. - 섹터 구분선은 두껍게. - 약
200종목까지 테스트했을 때 속도 저하가 크지 않았음. - 당장은 종목 수를 더
늘릴 필요 없다고 판단.

대시보드 첫 화면에 히트맵까지 항상 띄우면 초기 로딩이 길어질 수 있으므로
**사이드바에서 눌렀을 때 로드**하는 방식 유지.

# 26. 2026-09-04 추가 업데이트 — v3.44.0 / 시장 상태 문장엔진 v0.2

## 26.1 새 빌드

- 최신 빌드: **v3.44.0**
- 파일: `streamlit_app_3_44_0.py`
- 기존 종합위험지수 산식은 변경하지 않았다.
- 변경 범위는 시장 상태 해석 레이어와 모바일 내비게이션이다.

## 26.2 시장 상태 문장엔진 v0.2

v0.1 1년 1차 검토에서 다음 두 문제를 확인했다.

1. HY와 BBB처럼 같은 시장축의 지표를 각각 독립 확인으로 세면 신뢰도가 과대평가될 수 있음.
2. 강한 신호가 하루 임계값 아래로 내려갔다고 즉시 정상으로 복귀하면 문장이 `주의 → 정상 → 주의`처럼 출렁일 수 있음.

따라서 v0.2에서 다음을 반영했다.

- 신뢰도는 **지표 개수 대신 독립 시장축 개수**로 계산.
- 현재 1차 구현 독립축: 주식 / 변동성 / 금리 / 신용.
- HY + BBB는 합쳐서 `신용 1축`으로 계산.
- 1축 활성 = 약한/참고 신호, 2축 = 의미 있는 확인, 3축 이상 = 높은 신뢰도.
- 반대 증거가 있으면 문장 강도를 낮춤.
- 최근 5거래일 중 같은 축이 2일 이상 활성화됐으면 즉시 정상 복귀하지 않는 **hysteresis(상태 지속성)** 적용.
- 단일 축만 활성화된 경우 `위기`, `금융시장 전반의 불안` 같은 강한 표현 금지.

현재 연구용 초기 임계값:

- 주식축: S&P500 5일 -4% 이하 또는 20일 -7% 이하
- 변동성축: VIX 수준 + 5일/20일 상승 조합, VIX 27 이상은 자체 강한 단기 변동성으로 취급
- 금리축: 미국 10년물 5일 +15bp 이상 또는 20일 +40bp 이상
- 신용축: HY/BBB 5일·20일 확대속도로 확인

이 값들은 **시장 상태 연구용이며 기존 종합위험지수 확정 산식과 별개**다.

## 26.3 v0.2 회귀테스트 결과

합성 시나리오로 엔진 로직을 회귀검사했다.

- 정상장 → 활성 독립축 0개, `뚜렷한 단기 스트레스 확산 신호는 많지 않음` → 통과
- 금리 단독 급등 → 금리 1축, 변동성·신용 안정 문장으로 강도 제한 → 통과
- 주식 급락 + VIX 급등 + 신용 안정 → 주식/변동성 2축, `신용시장 확산은 아직 아님` → 통과
- 주식 급락 + VIX 급등 + HY/BBB 확대 → 주식/변동성/신용 3축, 높은 신뢰도 → 통과
- VIX가 이틀 강하게 급등 후 현재 임계값 아래로 내려온 경우 → 최근 5일 지속성으로 변동성축이 바로 꺼지지 않음 → 통과

따라서 v0.2의 **독립축 기반 confidence + 상태 지속성** 로직은 코드 수준 회귀테스트를 통과했다.

주의: 이 실행 환경에서는 FRED 원자료 CSV를 직접 내려받는 외부 네트워크 연결이 차단되어 있어, v0.2로 약 250거래일 전체를 다시 계산한 정량 통계는 아직 완료하지 못했다. 앱 실행 환경에서는 기존 데이터 공급 로직을 그대로 사용한다. 완전한 1년 재백테스트는 실제 시계열을 확보한 환경에서 계속한다.

## 26.2 프로그램 전반 공통 판정 원칙

이번 버전부터 시장 상태 전용이 아니라 향후 프로그램 전반의 규칙 설계에도 아래 원칙을 공통 연구자산으로 사용한다.

1. **판정 구조는 통일하되 기준은 지표별로 다르게 둔다.**
2. 각 지표는 가능하면 `Level(현재 수준)`과 `Change(변화속도)`를 따로 계산한다.
3. 지표 성격상 Level 또는 Change 중 **하나만 비정상이어도 정상 판정을 해제**할 수 있다.
4. Level과 Change를 단순 평균하지 않는다. 기본은 더 나쁜 쪽을 우선하고, 둘이 동시에 악화되면 한 단계 강화할 수 있다.
5. 경제적 의미가 이미 확립된 기준이 있으면 이를 우선 참고하고, 그렇지 않은 지표는 자기 역사적 분포 / percentile / 표준화된 변화폭을 사용한다.
6. 주가·금리처럼 구조적 절대수준이 시대에 따라 크게 달라지는 지표는 Level보다 변화속도·상대관계를 더 중시한다.
7. 금·구리·WTI·FX처럼 방향 하나만으로 위험을 단정하기 어려운 지표는 **급변 여부만 독립적으로 표시**하고 최종 위험 문장은 다른 시장축과 교차 확인한다.
8. `확인 부족`을 억지로 `정상`으로 바꾸지 않는다.
9. 기존 종합위험지수 점수와 시장상태의 `이상/급변` 판정은 서로 다른 개념으로 유지한다.

- St. Louis Fed FSI 개편: 금리·주가에서는 절대수준 대신 **변화**를 사용하는 방식 참고.

## 26.3 v0.3 지표별 판정 기준 초안

### 주식

S&P500 / Nasdaq / Russell은 가격 자체의 역사적 percentile을 사용하지 않는다.

- 5일 수익률: 약 -2.5% 관찰 / -4% 주의 / -7% 위험
- 20일 수익률: 약 -5% 관찰 / -8% 주의 / -12% 위험
- 최근 252거래일 고점 대비 낙폭: -5% 관찰 / -10% 주의 / -20% 위험
- 5일 하락이 자기 최근 약 2년 변동분포 상위 10% 이내면 최소 관찰, 상위 2.5% 이내면 최소 주의
- Level(낙폭)과 Change(5·20일 하락)가 동시에 비정상이면 한 단계 강화 가능

200DMA 이격:

- -3% 이하 관찰 / -7% 이하 주의 / -12% 이하 위험
- +12% 이상은 상방 과열 관찰 / +18% 이상 주의

Equal Weight 상대강도(RSP 20일 - SPY 20일):

- -2%p 이하 관찰 / -4%p 이하 주의 / -7%p 이하 위험

실제 상승종목 비율 / 200DMA 위 종목 비율 / 52주 신고가·신저가는 아직 전용 공급원 미연결. `확인 부족` 유지.

### 금리

EFFR 절대수준은 단독 위험판정하지 않고 `참고`로 표시한다.

2Y / 10Y / 30Y 변화:

- 5일 절대변화: 15bp 관찰 / 25bp 주의 / 40bp 위험
- 20일 절대변화: 35bp 관찰 / 55bp 주의 / 80bp 위험
- 자기 최근 약 2년 변화분포 상위 10%면 최소 관찰, 상위 2.5%면 최소 주의
- 상승과 하락 모두 `급변`으로 감지하되, 시장 스트레스 문장에서는 방향을 별도로 해석

수익률곡선:

- 10Y-2Y와 **10Y-3M**을 별도 카드로 표시
- 0 미만 역전은 관찰, 약 -1.0%p 이하 깊은 역전은 주의
- 20일 약 50bp 이상 급격한 변화는 관찰, 80bp 이상은 주의
- 역전 해소 자체를 자동으로 `안전`으로 보지 않고 상태전환으로 관찰

### 변동성 VIX

VIX는 Level과 Change 모두 단독 경보 가능.

Level 초안:

- 15 미만: 안정
- 15~20: 정상
- 20~25: 관찰
- 25~30: 주의
- 30 이상: 위험

Change 초안:

- 5일 +20% 관찰 / +35% 주의 / +60% 위험
- 20일 +35% 관찰 / +60% 주의 / +100% 위험
- Level과 Change가 동시에 비정상이면 한 단계 강화 가능

### 신용

HY OAS Level 초안:

- 3.5%p 미만 안정
- 3.5~4.5 정상
- 4.5~6.0 관찰
- 6.0~8.0 주의
- 8.0 이상 위험

HY OAS Change:

- 5일 +15bp / +30bp / +60bp = 관찰 / 주의 / 위험
- 20일 +30bp / +60bp / +120bp = 관찰 / 주의 / 위험

BBB OAS Level 초안:

- 1.3%p 미만 안정
- 1.3~1.8 정상
- 1.8~2.5 관찰
- 2.5~3.5 주의
- 3.5 이상 위험

BBB OAS Change:

- 5일 +8bp / +15bp / +30bp
- 20일 +18bp / +35bp / +70bp

HY와 BBB는 각각 Level OR Change 구조. 둘을 시장 전체 confidence에서 두 개의 독립축으로 중복 계산하지 않는 기존 v0.2 원칙은 유지.

### 경기·고용

Sahm Rule:

- 0.30%p 이상 관찰
- **0.50%p 이상 주의(공식 Sahm trigger 반영)**
- 0.75%p 이상 위험

신규실업수당:

- 4주 평균 사용
- 52주 저점 대비 +8% 관찰 / +15% 주의 / +25% 위험
- 약 8주 변화 +5% / +10% / +20% = 관찰 / 주의 / 위험
- 단순히 작은 폭의 `1년 신고가`라는 이유만으로 위험 처리하지 않음. 1년 percentile은 보조정보.

### 물가

공통:

- YoY = Level
- 최근 3개월 연율 = Momentum/Change
- 3개월 연율이 YoY보다 0.5%p 이상 높고 기준수준도 넘으면 `재가속`으로 강화

Core PCE는 Fed의 장기 2% 목표를 기준축으로 사용하며 v0.3에서는 2.5 / 3.0 / 4.0% 부근을 관찰 / 주의 / 위험 초안으로 둔다.

CPI / Core CPI는 PCE와 동일한 공식 목표값을 그대로 대입하지 않고 별도 완화된 기준을 사용한다.

### FX / 원자재

DXY / USDKRW / USDJPY / WTI / 금 / 은 / 구리:

- 절대 가격수준으로 위험 판정하지 않음
- 5일·20일 변화가 자기 최근 약 2년 분포에서 얼마나 이례적인지 계산
- 상위 10% 급변 = 관찰
- 상위 2.5% 급변 = 주의
- 기본적으로 단독 `위험` 판정은 제한
- Gold 상승=공포, Copper 하락=침체, WTI 상승=물가 재가속으로 단정 금지

- 은: Yahoo `SI=F` — COMEX 은 선물
- 구리: Yahoo `HG=F` — COMEX 구리 선물
- 원유: Yahoo `CL=F` — WTI 원유 선물

화면 명칭도 위와 같이 선물임을 명확히 표시합니다. 5일·20일 변화, 역사적 이례성 및 다른 시장축과의 동행을 중심으로 보고, 월물 교체·콘탱고·백워데이션 때문에 생긴 변화가 실제 위험 신호로 과대판정되지 않는지 확인합니다. Gold 상승=공포, Copper 하락=침체, WTI 상승=물가 위험으로 단정하지 않는 기존 원칙은 유지합니다.

## 30.5 데이터 공급원과 토스증권 API

다음 정식 빌드에서는 현재 공급원을 유지합니다.

- 경제·금리·신용: FRED 및 미국 재무부
- 보조 가격·지수·원자재 선물: Yahoo Finance
- 뉴스: Google News RSS

토스증권 Open API 연동은 이번 구현 범위에서 제외하고 별도 후속 실험으로 미룹니다. 이유는 API 키 발급, 인증 및 토큰 갱신, 지원 종목·지수·환율·이력 범위, 호출 제한, 응답속도와 Yahoo 대비 가격 차이를 먼저 검증해야 하기 때문입니다.

후속 실험 시에는 주문 기능을 연결하지 않은 읽기 전용 어댑터부터 만들고, 토스와 Yahoo를 일정 기간 병행 수집한 뒤 동일 상품·통화·거래일·수정주가 기준을 확인합니다. 검증되면 미국 주식·ETF는 토스 우선, 토스 미지원 지수·원자재 선물은 Yahoo 보조, 공식 경제통계는 FRED/미 재무부 유지의 혼합 구조를 검토합니다. API 키와 비밀값은 코드·문서·GitHub에 절대 커밋하지 않습니다.
