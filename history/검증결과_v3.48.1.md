# v3.48.1 검증 결과

작성: 2026-09-07. 비교 기준: v3.48.0.

## 기능 검증

자동 테스트 35개 통과. 뉴스 화면 테스트를 카드형 필터 기준으로 갱신해 기존 `selectbox`가 제거됐는지, 카테고리 카드와 기사 수가 출력되는지, URL 카테고리 선택 후에도 네트워크 재요청 없이 화면이 정상 실행되는지 확인했습니다. 기존 작업 중복 방지, 병렬 수집, 캐시 보존, 실제 앱 5개 페이지 실행 및 시장현황 판정 테스트도 모두 유지됩니다.

Streamlit AppTest와 네트워크 mock을 사용했습니다. Windows/아이폰 실기기 또는 실제 브라우저 픽셀 검증을 의미하지 않습니다. Python 문법 검사 통과.

## 성능 측정

| 대상 | 이전/첫 계산 | 개선/캐시 사용 | 조건 |
|---|---:|---:|---|
| FRED CSV 변환 | 0.5341초 | 0.0085초 | 동일 1,253행, 5회 중앙값, 결과 동일 확인 |
| 11개 요청 처리 | 0.5517초 | 0.1521초 | 요청마다 0.05초 모의 지연, 순차→최대 4개 병렬 |
| 시장현황 평가 | 0.1076초 | 0.0036초 | 기존 12개 원자료, 첫 계산과 동일 자료 캐시 5회 중앙값 |

이는 구성요소 측정입니다. 전체 앱이 같은 비율로 빨라진다는 뜻은 아닙니다. 인터넷 응답시간, 사용자 PC, 디스크 속도, 캐시 유무에 따라 달라집니다. 실제 외부 서버 전체 로딩 벤치마크는 수행하지 않았습니다.

## 계산 동일성

종합위험지수 핵심 함수 12개 AST 동일 확인. market_engine.py 원문 동일. 위험점수 산식·가중치·시장현황 임계값 변경 없음. 뉴스 분류 모듈은 위험 계산 모듈을 가져오거나 호출하지 않습니다.

## v3.48.1 UI 변경 확인

- 뉴스 카테고리 `전체`와 9개 분류를 카드형 링크로 표시합니다.
- 각 카드에 현재 저장 자료 기준 기사 수를 표시합니다.
- 선택 카드는 텍스트, 배경, 테두리로 함께 구분합니다.
- 데스크톱 5열, 780px 이하 모바일 2열 반응형 규칙을 적용했습니다.
- 선택값은 `news_category` URL 매개변수로 유지하며 허용되지 않은 값은 `전체`로 되돌립니다.
- 뉴스 기사 내용, 분류 규칙, 수집 주기 및 금융 점수 계산은 변경하지 않았습니다.

## 이번에 발견해 수정한 문제

- 공통 위험 계산을 시장현황 경로에서 제거한 뒤 남은 overall 증감 참조를 발견해 위험 화면 경로로 이동.
- RSS 발행시각의 타임존이 없을 때 timezone 이름이 정의되지 않은 문제 수정.
- 자동/수동/초기 데이터 수집에 같은 작업 키를 사용해 파일 쓰기 충돌 가능성 완화.
- 새로고침이 중복 작업 때문에 생략된 경우 계속 로딩 중으로 남지 않도록 실행 상태 확인.

## 한계와 후속 검증

처음 실행하고 캐시가 전혀 없으면 실제 자료가 도착할 때까지 기다려야 합니다. 준비 상태를 즉시 표시하고 뉴스/시장맵으로 이동할 수 있도록 했습니다. 금융 화면은 기존 필수 지표 8개가 준비돼야 진입합니다. 보조지표의 준비상태는 2초 간격으로 화면에 반영합니다.

작업 중복 방지는 단일 프로세스 범위입니다. 여러 서버 프로세스가 같은 캐시 폴더를 공유하는 배포는 별도 분산 잠금이 필요합니다. 지표 임계값 보정 및 발표 당시 자료를 이용한 백테스트는 이번 작업 범위에 포함하지 않았습니다.
