## 점검에서 확인한 것

- 금은 96/250일(38.4%), 은은 116/250일(46.4%)에 관찰 또는 주의. 5/20일 중 하나라도 충족하면 신호가 반복될 수 있으므로, 백분위 90이라고 전체 경보율 10%를 보장하지 않습니다. 잦은 경보가 실제 큰 움직임을 반영하는지 또는 기준이 민감한지는 스트레스/평온 구간 비교로 보정해야 합니다.
- 이름이 동일하게 붙은 RSP/SPY Series를 병합할 때 열 이름을 숫자라고 가정하던 오류를 발견해 위치 기반 접근으로 수정하고 회귀 테스트 추가.
- 내려받은 실업률 자료에 2025-10 관측이 없습니다. 누락된 월을 앞뒤 월로 채워 3개월/12개월로 오인하지 않도록 확인 부족 처리. UNEMP/Sahm은 해당 기간 211일 판정 보류.
- 공급원 다운로드 일부가 네트워크 승인 단계에서 중단됨. 확보된 파일만 사용한 offline 모드로 실행. 미확보 데이터는 0이나 정상으로 대체하지 않음.
- 자료가 없으면 원인 해석과 정상 판정을 보류하는 동작 확인.
