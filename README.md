# 미국 증시 종합위험지수 v3.49.0

이번 빌드는 뉴스·시장상태 화면을 단순화하고 CPI 월간 자료 누락 처리와 원자재 선물 명칭을 개선했습니다.

## Windows 실행 방법

1. ZIP을 **전부 압축 해제**하세요.
2. Python이 설치되어 있어야 합니다. Python 3.11 이상을 권장합니다.
3. 처음 사용한다면 `install_windows.bat`를 실행해 필요한 패키지를 설치하세요.
4. 설치 후 `start_windows.bat`를 더블클릭하세요. 브라우저에서 프로그램이 열립니다.

프로그램이 실행 중일 때 열린 명령창은 유지하세요. 같은 폴더의 `.py` 파일들이 함께 필요합니다.

직접 명령어로 실행하는 경우:

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

## 달라진 점

- 뉴스 페이지의 별도 `새로고침` 버튼을 제거하고 저장 캐시 선표시와 자동 백그라운드 갱신만 유지.
- 시장상태의 지표별 `해석과 판정 기준` 펼침 영역을 제거하고 현재값·상태·변화·핵심 신호 중심으로 표시.
- CPI·근원 CPI·근원 PCE는 정확히 12개월 전과 3개월 전 달력값을 각각 확인해 계산. 한쪽 기준월만 빠지면 가능한 계산은 계속 표시.
- 최근 16개월 CPI 계열 캐시에 월 누락이 있으면 FRED 전체 시계열을 재요청해 자동 복구.
- 자료 없음, 특정 기준월 누락, 최신 발표 대기 가능성, 필요 이력 부족을 구분해 표시.
- 금·은·구리·WTI를 화면에서 선물가격으로 명시.
- 뉴스 카테고리를 아이콘·이름·기사 수가 표시되는 10개 카드로 구분.
- 선택한 카드는 강조색과 테두리로 표시하며, 모바일에서는 2열로 배치.
- 카테고리 선택 상태를 URL에 보존해 새로고침 후에도 같은 분류 유지.
- 시장현황 보조지표 11개: 최대 4개 동시 수집, 완료된 항목부터 저장 및 표시.
- 보조지표 캐시를 디스크에 보관해 재실행 때 재사용. 항목별 마지막 성공 시각 기준 10분 갱신.
- 뉴스·시장맵: 공통 시장 데이터와 위험지수 계산을 기다리지 않고 진입.
- 뉴스·시장맵의 이전 캐시를 먼저 표시하고 백그라운드로 갱신. 실패해도 기존 자료 유지.
- 처음 실행 시 진행상태와 뉴스/시장맵 이동 경로를 먼저 표시. 필수 지표를 우선 요청하고, 준비되면 화면 진입.
- FRED CSV 날짜·숫자 변환을 일괄 처리.
- 시장현황 판정 결과는 데이터 내용과 기준일을 키로 캐시. 자료 변경 시 다시 계산.
- 갱신 작업 중복 실행 방지. 이 잠금은 하나의 Python 프로세스 안에서 적용됨.

## 뉴스 카테고리

주요 뉴스 / 연준·금리 / 경기·고용 / 물가 / 기업·실적 / 기술·AI·반도체 / 정책·무역 / 지정학·에너지 / 한국 관련.

제목의 명시적 키워드 규칙으로 대표 카테고리와 보조 태그를 붙입니다. 일치하는 키워드가 없으면 수집 카테고리를 사용합니다. 보조 태그로도 필터링할 수 있습니다. 본문을 읽거나 긍정·부정 평가를 하지 않습니다. `주요 뉴스`는 시장 종합 수집 분류이며 중요도를 평가한 순위가 아닙니다.

**뉴스는 종합위험지수·시장현황 판정에 반영하지 않습니다.**

## 검증 범위

검증결과_v3.49.0.md 및 performance_results.json을 확인하세요. 실제 인터넷을 통한 전체 로딩 시간, Windows와 실제 아이폰 화면은 별도 확인이 필요합니다. 기존 지표 임계값 보정과 전체 역사 검증은 아직 남아 있습니다. `audit/`는 v3.47.0에서 수행한 부분 역사 점검이며 이번 기능 검증과 구분합니다.

```bash
python -m unittest discover -s tests -v
```

이번 파일은 Streamlit 소스 빌드입니다. Python 없이 실행하는 단독 EXE는 아닙니다.
